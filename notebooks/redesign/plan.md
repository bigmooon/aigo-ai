## 목표·방식
- 20~30대 임차인에게 근거를 찾아 쉬운 말로 답한다. 법률 판단을 대신하지 않는다.
- 임대차 중심. 청년 주거 정책은 외부 검색 연결 후 답변할 대상으로 유지하되 이번 단계에서는 검색 도구를 구현하지 않는다. 과거 법령은 판본·최신성 검증 사례로 유지한다.
- redesign과 기존 app/tests/harness 위치 유지. 새 구현·테스트는 노트북에서 작성 후 검증된 셀만 추출한다.
- 작은 함수·명확한 이름·입출력 docstring·이유를 설명하는 주석. 불필요한 상속·wrapper·프레임워크 금지.
- 기존 서비스 전체를 노트북으로 옮기지 않고 실제 변경 부분만 전환한다.
- RunPod에서 sLLM 7~8B급 2개 우선 비교. GPU·모델·양자화·요금·시간 한도는 실행 전 승인한다.
- reranker/rewrite/멀티 에이전트는 필요를 입증한 경우 비교한다.
