# 통합 검토
기존 질문 45개를 그대로 연결하고 과거 근거 후보를 보존했다. 실제 답변의 정답 확정은 아직 아니다.
새 커널·추출 일치·22개 테스트 및 12개 subtest가 통과했다.
과거 API 기록은 비실행 부록이며 새로운 판본 검증으로 주장하지 않는다.
기존 공개 질문은 개발용이다. 최종 독립 holdout이라고 주장하지 않는다.
현재 의미 중복·정답 검토를 이유로 질문 읽기 자체를 막지 않는다. 정식 비교 준비 검사는 별도 도구다.
개선/회귀 사례: 실제 서비스 비교 0개.
미해결: 정답 판본 검토, Before 답변 확보, 독립 최종 평가 질문 준비.
심각한 답변 오류: 답변 실험을 하지 않았으므로 미검토.
사용자 승인으로 통합 구조를 채택했다. Git 반영은 별도 승인 대기다.
