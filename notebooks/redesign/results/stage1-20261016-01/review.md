# 단계 1 로컬 검증 — Critical Review

## 문제와 결과
기존 Hit와 Recall의 혼동을 합성 fixture로 분리했다. 근거 2개 중 하나를 2위에서 찾으면 Hit=1, Recall=0.5, Precision@5=0.2, MRR=0.5다. 이는 서비스 Before/After 결과가 아니다.

- 새 커널 순차 실행과 export 일치 통과.
- 평가 11개 + 기존 추출/SSE 11개: 22 passed, 12 subtests passed (11.37s).
- 60개 초안의 split 개수·ID·동일 질문 검사 통과, 미검토 상태의 ready 실행 차단 확인.
- 다른 판본 ID에는 정답 판본의 득점을 주지 않는 합성 테스트 통과. 실제 판본 내용의 적합성 검증은 하지 않았다.
- Windows Jupyter 이벤트 루프 경고가 있었으나 실행 성공. 네트워크 API·GPU·패키지 설치 없음.

## 누수·공정성
질문은 합성 초안이다. scenario_id를 서로 다르게 지정한 사실만으로 의미 독립성을 입증할 수 없다. 사용자가 기존 v1·dev와의 의미 중복을 확인하고 holdout 튜닝이 있었다면 교체해야 한다. 기존 v1와 점수 직접 비교를 금지한다.

정답은 모두 null이다. 검토되지 않은 점수를 0이나 만점으로 만들지 않는다. 사용자 단독 채점은 평가자 일치도와 완전한 블라인드를 보장하지 못한다. dev 10개 보정은 실제 답변 확보 후 수행한다.

## 복잡도·운영
표준 라이브러리 함수 6개이며 평가 프레임워크·모델 호출을 추가하지 않았다. 서비스 변경이 없어 기존 SSE 검사를 실행했고 전체 API·Qdrant 통합은 이번에 검증하지 않았다. .gitignore는 private 라벨의 우발적 Git 추가를 줄이지만 접근 통제가 아니다.

## 사례·심각한 오류
- 개선 사례: 실제 서비스 비교 0개.
- 회귀 사례: 실제 서비스 비교 0개.
- 미해결 3개: 정답 판본 라벨, 의미 중복 검토, 실제 답변 10개의 사람 채점표 보정.
- 심각한 서비스 오류 검토: 실제 답변이 없어 미실시. 오류가 없다고 판정하지 않는다.

## 결정
계산 코드는 로컬 검증을 통과했다. 단계 전체는 사용자 정답 검토 대기이며 Git 반영도 별도 승인 대기다. 다음 단계·모델 선택을 자동으로 시작하지 않는다.
